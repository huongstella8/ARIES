Writing Task 1 – Graphs: Core Practice Set

From reading a chart to writing a 150-word report: analyse, select, organise and use the right language. Original charts are unchanged. Work through each exercise, press Check answers, then finish with the timed writing task.

The 5-step Task 1 routine (use it every time)
  1. Analyse (1 min): title, axes/units, what the bars, lines or segments represent, time period.
  2. Select (2 min): highest, lowest, biggest change, overall trend, similarities. Do not describe every number.
  3. Organise (1 min): Introduction (paraphrase the title) → Main body 1 → Main body 2 (group similar data; compare) → Summary (overview, no new data).
  4. Write (14 min): simple, accurate sentences; correct tense; trend verbs + adjectives/adverbs; comparatives.
  5. Check (2 min): data accuracy, tense, spelling of key vocabulary, no personal opinion.
